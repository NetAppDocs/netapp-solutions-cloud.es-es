= Cifrado de datos en reposo
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Todos los volúmenes de Google Cloud NetApp Volumes están cifrados en reposo mediante cifrado AES-256, lo que significa que todos los datos del usuario escritos en los medios están cifrados y solo se pueden descifrar con una clave por volumen.

* Para NetApp Volumes-SW, se utilizan claves generadas por Google.
* Para NetApp Volumes-Performance, las claves por volumen se almacenan en un administrador de claves integrado en Google Cloud NetApp Volumes.


A partir de noviembre de 2021, estuvo disponible la vista previa de la funcionalidad de claves de cifrado administradas por el cliente (CMEK).  Esto le permite cifrar las claves por volumen con una clave maestra por proyecto y por región alojada en https://cloud.google.com/kms/docs["Servicio de administración de claves de Google (KMS)."^] KMS le permite conectar administradores de claves externos.

Para obtener información sobre cómo configurar KMS para NetApp Volumes-Performance, consulta https://docs.cloud.google.com/netapp/volumes/docs/configure-and-use/cmek/cmek-overview["Configuración de claves de cifrado administradas por el cliente"^].
