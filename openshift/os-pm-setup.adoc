= Implementar y configurar la plataforma Managed Red Hat OpenShift Container en AWS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Esta sección describe, a grandes rasgos, un flujo de trabajo para configurar clústeres de Red Hat OpenShift gestionados en AWS(ROSA). Muestra el uso de Amazon FSx for NetApp ONTAP (FSx ONTAP) gestionado como backend de almacenamiento de Trident para proporcionar volúmenes persistentes. Se proporcionan detalles sobre la implementación de FSx ONTAP en AWS mediante NetApp Console. Además, se proporcionan detalles sobre el uso de NetApp Console y OpenShift GitOps (Argo CD) para realizar actividades de protección y migración de datos para las aplicaciones con estado en clústeres ROSA.

Aquí hay un diagrama que representa los clústeres ROSA implementados en AWS y que utilizan FSx ONTAP como almacenamiento de backend.

image:rhhc-rosa-with-fsxn.png["Figura que muestra el diálogo de entrada/salida o representa contenido escrito"]


NOTE: Esta solución se verificó utilizando dos clústeres ROSA en dos VPC en AWS.  Cada clúster ROSA se integró con FSx ONTAP mediante Trident.  Hay varias formas de implementar clústeres ROSA y FSx ONTAP en AWS.  Esta descripción de alto nivel de la configuración proporciona enlaces a la documentación para el método específico que se utilizó.  Puede consultar los otros métodos en los enlaces correspondientes que se proporcionan en ellink:os-solutions-resources.html["sección de recursos"] .

El proceso de configuración se puede dividir en los siguientes pasos:

.Instalar clústeres ROSA
* Cree dos VPC y configure la conectividad de emparejamiento de VPC entre las VPC.
* Consulta link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4["aquí"^] para ver instrucciones para instalar clústeres ROSA.


.Instalar FSx ONTAP
* Instala FSx ONTAP en las VPC desde NetApp Console. Consulta link:https://docs.netapp.com/us-en/console-setup-admin/index.html["aquí"] para crear una cuenta de NetApp Console y empezar. Consulta link:https://docs.netapp.com/us-en/cloud-manager-fsx-ontap/index.html["aquí"] para instalar FSx ONTAP. Consulta link:https://docs.netapp.com/us-en/console-setup-admin/index.html["aquí"] para crear un conector en AWS para gestionar FSx ONTAP.
* Implemente FSx ONTAP mediante AWS.  Referirselink:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/getting-started-step1.html["aquí"] para implementación mediante la consola de AWS.


.Instalar Trident en clústeres ROSA (usando el gráfico Helm)
* Utiliza el chart de Helm para instalar Trident en clústeres ROSA. Consulta el enlace a la documentación: https://docs.netapp.com/us-en/trident/trident-install/kubernetes-deploy-helm.html[aquí^].

* Referirselink:https://docs.netapp.com/us-en/trident/trident-use/backends.html["aquí"] Para obtener detalles sobre la creación de clases de almacenamiento y backend.
* Haga que la clase de almacenamiento creada para FsxN con Trident CSI sea predeterminada desde OpenShift Console.  Vea la captura de pantalla a continuación:


image:rhhc-default-storage-class.png["Figura que muestra el diálogo de entrada/salida o representa contenido escrito"]

.Implementar una aplicación usando OpenShift GitOps (Argo CD)
* Instala el operador OpenShift GitOps en el clúster. Consulta las instrucciones link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.10/html/cicd/gitops#installing-openshift-gitops["aquí"^].
* SetUp una nueva instancia de Argo CD para el clúster. Consulta las instrucciones link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.10/html/cicd/gitops#gitops-argo-cd-installation_setting-up-argocd-instance["aquí"^].


Abre la consola de Argo CD e implementa una aplicación. Como ejemplo, puedes implementar una aplicación de Jenkins con Argo CD usando un Helm Chart. Al crear la aplicación, se proporcionaron los siguientes detalles: Project: default cluster: +'https://kubernetes.default.svc'+[] (sin las comillas) Namespace: Jenkins la url del Helm Chart: +'https://charts.bitnami.com/bitnami'+[] (sin las comillas)

Parámetros de Helm: global.storageClass: fsxn-nas
