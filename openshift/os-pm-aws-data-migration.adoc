== Migración de datos

El servicio Red Hat OpenShift en AWS así como Amazon FSx for NetApp ONTAP (FSx ONTAP) forman parte de la cartera de servicios de AWS.  FSx ONTAP está disponible en opciones Single AZ o Multi-AZ.  La opción Multi-Az proporciona protección de datos ante fallas en la zona de disponibilidad.  FSx ONTAP se puede integrar con Trident para proporcionar almacenamiento persistente para aplicaciones en clústeres ROSA.

La migración de aplicaciones de contenedores implica:

* Volúmenes persistentes: esto se puede lograr utilizando BlueXP.  Otra opción es utilizar Trident Protect para gestionar las migraciones de aplicaciones de contenedores desde el entorno local al entorno de la nube.  La automatización se puede utilizar para el mismo propósito.
* Metadatos de la aplicación: esto se puede lograr utilizando OpenShift GitOps (Argo CD).
